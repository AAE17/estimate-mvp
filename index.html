દરેક કામના સ્ટેપ. ખોલો, વાંચો, એ જ ક્રમે કરો.

1. લૉગિન / સાઇન અપ
  1. soplus.in અથવા એપ લિંક ખોલો.
  2. Sign up: નામ, હોદ્દો, મોબાઇલ, ઈમેલ, પાસવર્ડ, જિલ્લો, તાલુકો.
  3. Super Admin મંજૂર કરે ત્યાં સુધી અંદર નહીં થાય.
  4. પછી ઈમેલ + પાસવર્ડથી Login.
2. પ્રોફાઇલ
  1. ઉપર જમણે 👤 દબાવો.
  2. નામ, હોદ્દો, R&B અને નાની સિંચાઈ ઓફિસ લખો.
  3. સેવ. 100% ભરાય તો એસ્ટીમેટ/બિલમાં નામ અને ઓફિસ આપોઆપ છપાશે.
3. એસ્ટીમેટ — CC / Paver / Gutter / Pipe
  1. + New Estimate અથવા Estimate ટૅબ.
  2. પ્રકાર પસંદ: CC Road, Paver Block, Gutter Line, Pipe Line.
  3. જિલ્લો → તાલુકો → ગામ, Grant Head + વર્ષ, કામનું નામ, મંજૂર રકમ.
  4. લંબાઈ / પહોળાઈ. CCમાં જાડાઈ. વધુ પહોળાઈ હોય તો Add.
  5. લાઇવ રકમ જુઓ. Paverમાં Brass પણ.
  6. Excel, PDF અથવા બંને. બને ત્યાં સુધી ફોર્મ ન અડશો.
4. સાઇટ માપ
  1. Site ટૅબ. New work અથવા Ongoingમાં એસ્ટીમેટ પસંદ.
  2. લંબાઈ-પહોળાઈ લખો. CCમાં જાડાઈ. 10+15 લખો તો સરેરાશ.
  3. કોન્ટ્રાક્ટરનું નામ આ માપ માટે અલગ હોઈ શકે.
  4. Site plan = આંગળીથી સ્કેચ. Photo = કેમેરા, GPS જો મંજૂરી હોય.
  5. Save. Work done યાદીમાં આવશે. આંખ = ખોલો, ડસ્ટબિન = કાઢો.
5. કાચું બિલ
  1. સાઇટ માપ સેવ પછી Check, કામ ખરેખર પૂરું થયું?
  2. રકમ / Brass પોપઅપ જુઓ.
  3. કાચું બિલ દબાવો. તકતી/ટેસ્ટ 0 કરી શકાય.
  4. બરાબર લાગે તો Excel / PDF સેવ.
6. પાકું બિલ
  1. Bill ટૅબ. ત્રણ રસ્તા: એસ્ટીમેટ પરથી, સેવ કરેલ માપ પરથી, નવી સાઇટ.
  2. કામ પસંદ. Grant / Year આપોઆપ આવે તો ચેક કરો.
  3. ગામ, તાલુકો, DEE, AAE, વર્ક ઓર્ડર, TS, મંજૂર રકમ, શરૂ/પૂર્ણ તારીખ, MB નંબર, પાના.
  4. Qty લખો. બાજુમાં લાઇવ બિલ જુઓ.
  5. Excel, PDF અથવા બંને.
7. ફોરવર્ડિંગ લેટર
  1. ફોરવર્ડિંગ લેટર ટૅબ.
  2. બિલ બન્યાની તારીખ પસંદ. એ જ દિવસના બિલ આવશે.
  3. વહી નંબર, પત્ર તારીખ, ઓડિટ માટે જિલ્લા પંચાયત.
  4. કામ પર ટિક. DEE R&B અથવા નાની સિંચાઈ + ઓફિસ સરનામું.
  5. એક MBમાં ઘણા કામ હોય તો બધા ટિક કરો. Excel/PDF.
8. ટૂર ડાયરી અને ફોટો
  1. Diary: આજની તારીખ. એસ્ટીમેટ, સાઇટ, બિલ આપોઆપ ગણાશે.
  2. ફોટો/સ્કેચ ફક્ત તમારા ખાનગી ફોલ્ડરમાં. બીજા યુઝરને નહીં દેખાય.
  3. ખોલો લિંક 10 મિનિટ. યાદી ફરી ખોલો તો નવી લિંક.
